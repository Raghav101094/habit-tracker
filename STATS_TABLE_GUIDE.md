## 📋 Table Columns Explained

### 1. Habit Column
- **Icon + Name** - Your habit with its emoji
- **Color Bar** - Visual indicator under the name

### 2. Last 10 Days (Individual Columns)
- Shows the **last 10 days** of activity
- Each column header shows:
  - **Day name** (Mon, Tue, etc.)
  - **Date number** (6, 7, 8, etc.)
- **Green ✓** - Habit completed that day
- **Red ✗** - Habit missed that day
- Hover over the date to see full date

### 3. Monthly % Column
- Shows **completion percentage for current month**
- Calculated as: (Completed Days / Total Days in Month) × 100
- **Color coded:**
  - 🟢 **Green (80%+):** Excellent! You're doing great
  - 🟠 **Amber (50-79%):** Good, but room for improvement
  - 🔴 **Red (<50%):** Needs attention
- **Background:** Light blue highlight

### 4. Longest Streak Column
- Shows **longest consecutive streak this month**
- Only counts completed days within the current month
- **Includes:**
  - 🔥 Fire emoji (if streak > 0)
  - Number of days
  - "day" or "days" label
- **Background:** Light purple highlight

## 🧮 Calculation Details

### Monthly Percentage Formula
```
Monthly % = (Completed Days / Days in Current Month) × 100
```

**Example:**
- Month: January (31 days)
- Completed: 24 days
- Monthly %: (24 / 31) × 100 = 77%

### Longest Streak Algorithm
```
For each day in current month:
  If completed:
    Increment current streak
    Update longest if current > longest
  Else:
    Reset current streak to 0
```

**Example:**
- Days: ✓ ✓ ✗ ✓ ✓ ✓ ✗ ✓
- Streaks: 1 2 0 1 2 3 0 1
- Longest: 3 days
